# Unit-13-Code-Repositories-
Assignment
1. How would you setup GIT on a mac and PC

Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Install Git
brew install git

Or

Go to: https://git-scm.com/downloads
Choose Windows, and download the installer.
Step 2: Run the Installer
When the setup window appears:
Leave most settings as default.
Make sure “Add Git to PATH” is selected.
Choose your preferred terminal (recommended: “Git Bash”).
